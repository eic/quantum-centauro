# Recorded measurements — 4 October 2026

This directory contains completed measurements, not a new run generated by the notebook.

| Path | Contents |
| --- | --- |
| `operational/` | 900 measured fresh-process rows across ten fixed events and three methods, with timing and comparison summaries. |
| `prepared_default/` | 2,640 prepared Aer calls using the default thread policy. |
| `prepared_one_thread/` | 2,640 calls in a separate one-thread control scenario. |
| `frozen_inputs.json` | The shared set of 88 ordered candidate inputs used for prepared replay. |
| `manifest.json` | Snapshot file inventory. |

In each prepared scenario, a minimum was selected in 2,635 of 2,640 calls. This is not perfect selection. The prepared timing excludes external circuit construction and decomposition, but includes state-preparation gates and execution; it is not an end-to-end event-processing measurement. Operational timings include fresh-process startup, input loading, event selection, and output writing. The two timing scopes should not be treated as directly comparable evidence of speedup.

FastJet Centauro and Direct Centauro are distinct implementations. Direct active/classical comparisons are diagnostic and do not establish FastJet equivalence, universal accuracy, quantum hardware performance, or speedup. The data are a bounded sample of ten fixed events.
