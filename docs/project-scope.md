# Project Scope

## Outcome

The final public scope is a source-only local Aer selector and sibling EICrecon integration. It documents the C++/Python boundary, local wrappers, and hash-bound progress receipt. It does not include remote providers, hardware, grid execution, or a final performance aggregate.

## Original Plan

The supplied unpublished internship brief proposed a scalable quantum-as-a-service interface for EIC reconstruction, a quantum reconstruction payload, an Open Science Grid demonstration, documentation, and a final technical report.

## Final Public Scope

- Local Aer plus a recipient-built sibling EICrecon checkout.
- Copy-ready integration additions, local wrappers, strict request/reply validation, and source-inspected behavior.
- Accepted progress recorded by hash-bound external ledgers: shadow `7080/7080`, hard `600/600`, end-to-end `40/40`, and active `56/300` partial.
- An absent final aggregate and a recorded `comparison_layer_type_error` are explicit limitations.

The official EICrecon prerequisite is documented at [github.com/eic/EICrecon](https://github.com/eic/EICrecon). A pinned base revision is recorded in the integration guide; recipients acquire, build, and provide their own environment and fixtures.
